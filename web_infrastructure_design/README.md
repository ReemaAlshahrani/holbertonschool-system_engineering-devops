# Web Infrastructure Design

This directory contains documentation, technical explanations, and architecture diagrams for designing scalable, secure, and reliable web infrastructures as part of the Holberton School curriculum.

## Files Overview

| File Name | Description |
| :--- | :--- |
| `0-simple_web_stack.md` | Documents a basic single-server LAMP/LEMP stack, covering component breakdown, request flow, and inherent Single Points of Failure (SPOF). |
| `1-distributed_web_infrastructure.md` | Scales the setup into a multi-server architecture with a Load Balancer (HAproxy), two application servers, and a MySQL Primary-Replica database cluster. |
| `2-secured_and_monitored_web_infrastructure.md` | Enhances the architecture by adding 3 firewalls, an SSL certificate for HTTPS traffic, and 3 monitoring clients for real-time observability. |
| `3-scale_up.md` | Implements an advanced scaled architecture featuring a load balancer cluster, separated tiers (Web servers, Application servers, and Databases), and high availability. |
